# 本地文档问答（RAG）Demo

一个不依赖 LangChain / 向量数据库的最小 RAG 实现：PDF 解析 → 中文分块 → 字符级 BM25 检索 → 本地大模型带引用回答。
除 `numpy`、`pypdf` 外没有第三方依赖，方便看清每一步在做什么。

## 效果

```text
$ python app.py ask "模拟退火设置了多少次搜索？"
问题：模拟退火设置了多少次搜索？
检索：bm25 · 47 个块 · 1 ms

  [1] p.23  score=28.402  具体到该问题，模拟退火算法可以帮助我们处理各类数据的波动……
  [2] p.22  score=22.648  在本问题中，由于数据量极大，计算公式较为复杂，所以，我们选用启发式搜索-模拟退火算法……
  [3] p.1   score=17.419  但是，模型尚且存在不足，市场是一个复杂的大模型……

回答：
（离线模式，未调用大模型）与「模拟退火设置了多少次搜索？」最相关的原文：
- 第 23 页：2、设置模型搜索次数，由于我们的设备配置较好，所以这里我们选择 1000000 次为搜索次数。
```

装上 Ollama 后，回答由本地模型生成，并同样带页码出处。

## 架构

```text
PDF ──pypdf──> 页文本 ──按句切分、360 字/块、重叠 1 句──> chunks.json
                                                              │
问题 ──字符 unigram──> BM25 ──Top-K──> 拼上下文 ──> Ollama(qwen2.5) ──> 回答 + [页码]
```

- **分块**：按中英文句末标点切句，块间重叠 1 句，避免答案被切断；每块保留页码，回答可溯源。
- **检索**：中文没有分词，用字符 unigram 做 BM25（`k1=2.0, b=0.75`）；另保留 bigram 与 RRF 融合两种对照实现。
- **生成**：默认 `qwen2.5:7b`；提示词限定“只依据资料回答、没有就说没有”，要求标注页码。
- **降级**：检测不到 Ollama 时自动退回抽取式回答，保证离线也能演示整条链路。

## 快速开始

```bash
pip install -r requirements.txt

python app.py ingest                 # 解析 data/ 下的 PDF，生成 index/chunks.json
python app.py ask "这个乡村有多少个地块？"
python app.py eval                   # 跑评测集，输出 Hit@k / MRR
```

接本地模型（可选，推荐）：

```bash
# 安装 Ollama：https://ollama.com/download
ollama pull qwen2.5:7b
ollama serve

python app.py ask "这个乡村有多少个地块？" --backend ollama --stream
```

## 检索评测

语料是 29 页的参赛论文，清洗后切出 47 个块（丢弃中文占比低于 25% 的代码附录）；自建 15 道事实型问题，判定标准是“答案关键词同时出现在同一个块里”，取前 5 个块。

| 方案 | Hit@1 | Hit@3 | Hit@5 | MRR |
| --- | --- | --- | --- | --- |
| **unigram BM25（默认）** | **87%** | **93%** | **100%** | **0.913** |
| bigram BM25 | 53% | 87% | 93% | 0.706 |
| RRF 融合（unigram + bigram TF-IDF） | 73% | 93% | 100% | 0.828 |

结论：

1. 中文短问句上，bigram 太稀疏，一个字对不上就整段失配，unigram 明显更稳。
2. RRF 融合没有跑赢单路——两路信号同质（都基于字面匹配），融合只是放大了共同错误。要再提升，得引入语义向量（embedding）这类互补信号。
3. 预处理上把代码附录（中文占比 < 25%）直接过滤掉，块数从 91 降到 47，Hit@1 从 80% 提到 87%——脏数据比模型更影响效果。\n4. 所以默认保持最简单的 unigram BM25：少一个组件，少一类线上问题。

## 目录

```text
app.py              命令行入口（ingest / ask / eval）
rag/ingest.py       PDF 解析、清洗、分块、建索引
rag/retrieve.py     BM25 / TF-IDF / RRF / 检索器
rag/llm.py          Ollama 客户端、提示词、离线降级
rag/evaluate.py     Hit@k 与 MRR 评测
eval/questions.json 15 道评测题与标准答案关键词
data/               待索引文档
docs/INTERVIEW.md   项目讲解要点（面试用）
```

## 已知限制

- 只做字面检索，同义改写（“规划期” vs “2024—2030”）会漏；下一步接 `nomic-embed-text` 做混合检索。
- 单文档、单进程、全量重建索引；文档上千后需要增量索引与向量库。
- 评测集只有 15 题，指标有波动，只用于方案对比，不代表线上效果。
